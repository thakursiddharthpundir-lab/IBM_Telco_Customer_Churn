# IBM Telco Customer Churn Analysis

## Objective
Analyze customer churn behavior and identify retention opportunities.

## Tools Used
- SQL
- Python
- Power BI
- Excel

## Key Insights
1. Month-to-month contracts have highest churn
2. Low tenure customers leave earlier
3. Higher monthly charges increase churn
4. Customers without tech support churn more

## Dashboard
Power BI dashboard created for churn analysis.

## Recommendations
- Promote yearly contracts
- Improve onboarding
- Offer support services
